# Daily Paper Digest — 2026-05-07

## Theme
Today’s worthwhile papers were about **when internal structure actually constrains behavior**. The strongest ones either expose a structural failure of predictive learning, treat representation geometry as the object of control, or make skill structure explicit enough to support recomposition rather than imitation.

## Short overview
This was a **selective three-paper day**. I screened a wider batch, but only **three papers felt worth saving**.

The best paper today is **The Predictive-Causal Gap: An Impossibility Theorem and Large-Scale Neural Evidence**. It is not a new model but a sharp warning: prediction-optimized representations can systematically learn the wrong latent variables for causal use.

**Manifold Steering Reveals the Shared Geometry of Neural Network Representation and Behavior** is more conceptual than immediately deployable, but it has a clear transferable claim: steering should respect intrinsic geometry, not assume a flat activation space.

**Decompose and Recompose: Reasoning New Skills from Existing Abilities for Cross-Task Robotic Manipulation** is the most directly useful robotics paper in the batch. I am keeping it because it tries to make skill composition explicit instead of relying on raw trajectory retrieval, though I am less convinced by it than by the first two.

## Novelty / framing / baseline impact
- **World-model framing:** The Predictive-Causal Gap is a good citation when arguing that predictive objectives alone do not guarantee system-level understanding.
- **Representation intervention framing:** Manifold Steering is useful if you want to argue that latent control should respect learned conceptual geometry rather than rely on linear probes alone.
- **Robotics transfer baselines:** Decompose and Recompose is worth knowing if you need a baseline or related-work reference for explicit skill recomposition in cross-task manipulation.
- **Novelty threat:** Low direct novelty collision. The main value is sharper framing, reusable evaluation instincts, and a few mechanism ideas worth stealing.

## One-paragraph takeaway
The common lesson today is that internal structure matters only if it changes the computation the model can perform. **The Predictive-Causal Gap** says predictive training can prefer environmentally convenient latents over causally meaningful ones, even at scale. **Manifold Steering** argues that if representation geometry really matters, interventions should follow that geometry and not cut across it with linear edits. **Decompose and Recompose** tries to operationalize this same instinct in robotics by replacing raw action imitation with explicit skill decomposition and coverage-aware recombination. Across all three, the useful standard is the same: structure should not just be interpretable after the fact; it should constrain transfer, control, or robustness.
