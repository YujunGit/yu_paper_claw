# Daily Paper Digest — 2026-05-04

## Theme
Today’s strongest theme was **explicit control interfaces inside world modeling or 3D generation**. The keepers did not just claim better generation or better robotics; they inserted a more structured handle on the problem: segment maps, latent reasoning slots, predictive scene-graph edges, or optimized structured latent seeds.

## Short overview
This was a **good but still selective day**. I screened a broader batch from the latest arXiv drops and only **four papers felt worth saving**.

The best direct fit is **Being-H0.7**. Its main idea is strong: move future-aware reasoning into a compact latent interface that helps action generation, instead of paying the cost of explicit future-frame rollout.

**Map2World** is the strongest 3D-generation paper today. It matters less because it is trendy and more because it gives users an actual spatial control interface that can scale beyond rigid grid tiling.

**Predictive Spatio-Temporal Scene Graphs** is the cleanest “structured temporal memory” paper in the batch. **InpaintSLat** is narrower, but the mechanism is good: treat initial noise as a controllable variable in structured 3D latent diffusion instead of only steering the denoising path.

## Most relevant to current work
**Being-H0.7** is the best fit today. The reusable idea is **future-aware supervision on an explicit latent reasoning interface without committing to dense visual rollout as the planning substrate**.

## Novelty / framing / baseline impact
- **World-action framing:** Being-H0.7 is a good citation against the assumption that future prediction must mean future video prediction.
- **3D controllability framing:** Map2World supports the claim that large-scale 3D generation needs an explicit spatial control interface, not just bigger asset priors.
- **Persistent world-state framing:** PredictiveGraphs is useful when arguing that semantic maps should model temporal routines, not only current occupancy.
- **Generation-control mechanism:** InpaintSLat suggests that initialization itself can be part of the control mechanism in structured latent generation.
- **Novelty threat:** Low. None of these looks like a direct collision, but Being-H0.7 and Map2World both strengthen the broader case for explicit intermediate interfaces.

## One-paragraph takeaway
The worthwhile papers today share one useful instinct: if you care about control, temporal reasoning, or coherent large-scale generation, you should place structure at the interface where decisions are made. Being-H0.7 does this with latent reasoning slots aligned to future observations during training. Map2World does it with user-defined segment maps and latent fusion over large worlds. PredictiveGraphs does it with temporal Bayesian filters attached to scene-graph relations. InpaintSLat does it from the opposite direction: instead of only correcting the denoising trajectory, it optimizes the starting latent seed so the structure is compatible from the beginning.
